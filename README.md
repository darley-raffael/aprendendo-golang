# Aprendendo Go

Minha trilha de estudos de **Go**: projetos progressivos, tutoria socrática com o Claude Code, code review a cada entrega e revisão espaçada.
Gerado a partir do [learning-template](https://github.com/darley-raffael/learning-template).

## Trilha

Roadmap completo em [`ROADMAP.md`](ROADMAP.md). Progresso em [`progresso/PROGRESSO.md`](progresso/PROGRESSO.md).

| Fase | Tema | Projetos |
|---|---|---|
| 0 | Primeiros passos (6 micro-projetos) | `ola` → `senha`, depois `gowc` |
| 1 | Fundamentos pela CLI | `tarefas`, `logstat` |
| 2 | Sistema de tipos e design idiomático | `calc` (interpretador) |
| 3 | Concorrência | `linkcheck`, `thumbs` |
| 4 | Backend HTTP e persistência | `encurta` v1/v2 |
| 5 | CLIs e DevOps | `devkit` |
| 6 | Redes e sistemas distribuídos | `minikv` (mini Redis) |
| 7 | Microsserviços e observabilidade | `encurta` v3 |
| 8 | Performance e internals | otimizar `minikv` |
| 9 | Carreira | capstone, entrevistas, open source |

Toda fase abre com uma **rampa** de micro-projetos que isolam os conceitos novos, seguida de um diagnóstico, e só depois vem o projeto grande.
